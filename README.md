# ⚡ Electric Vehicle Data Analysis Dashboard

## 📊 Project Overview
This project presents an interactive dashboard built using Tableau to analyze Electric Vehicle (EV) data, including trends, adoption, and performance insights.

## 🔗 Live Dashboard
👉 https://public.tableau.com/views/ELECTRICVEHICLEDATAANALYSIS_17744868983890/Dashboard1

## 📌 Key Insights
- EV adoption trends over time
- Regional distribution of electric vehicles
- Comparison of EV types and performance
- Key KPIs for decision-making

## 🛠 Tools & Technologies
- Tableau Public
- Data Cleaning & Transformation
- Data Visualization
